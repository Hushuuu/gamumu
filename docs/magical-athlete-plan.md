# 《Magical Athlete 搞怪運動會》完整規則整理

本規則涵蓋遊戲配件、選秀、競賽流程、移動判定、能力觸發順序、特殊賽道、計分、特殊情況、雙人及三人變體，以及 36 名角色的能力說明。

規則來源： [Magical Athlete 英文完整規則書](https://www.rulespal.com/magical-athlete/rulebook)。

## 一、遊戲基本資料

| 項目     | 規則               |
| ------ | ---------------- |
| 遊戲人數   | 2～6 人            |
| 遊戲場數   | 固定 4 場           |
| 選手數量   | 每位玩家 4 名（一般規則）   |
| 每場參賽   | 每位玩家派出 1 名未使用的選手 |

| 平手     | 並列獲勝，不另行加賽       |

## 三、遊戲設置

1. 將賽道板放置桌面中央，Mild Mile 面朝上。
2. 將金色冠軍與銀色亞軍積分片分別堆疊，高分在下、低分在上。
3. 洗勻全部 36 張選手卡牌，形成抽牌堆。
4. 將全部選手棋子放在方便拿取的位置。
5. 每位玩家取得一顆六面骰。
6. 進行選手選秀。

## 四、選手選秀規則

### 4.1 選秀數量

| 玩家人數 | 每次公開卡牌 | 每位玩家最終取得 |
| ---- | ------ | -------- |
| 3 人  | 6 張    | 4 張      |
| 4 人  | 8 張    | 4 張      |
| 5 人  | 10 張   | 4 張      |
| 6 人  | 12 張   | 4 張      |

雙人遊戲使用獨立變體規則。

### 4.2 選秀順序

1. 所有玩家擲骰，最高者成為首位選秀玩家。
2. 擲骰同點時，依規則比較下一高點數者；全員同點則重擲。
3. 依順時針方向，每位玩家選取一張公開選手卡。
4. 最後一位玩家選完後，立即反轉順序，由該玩家開始逆時針選取第二張。
5. 第一輪選秀結束後，每人持有 2 張卡牌。
6. 再公開玩家人數兩倍的全新選手卡。
7. 第二輪選秀由原首位選秀玩家左手邊的玩家開始，再次執行蛇形選秀。
8. 結束後，每位玩家持有 4 張選手卡。

例如四人 A、B、C、D，第一輪順序為：

`A → B → C → D → D → C → B → A`

第二輪由 B 開始：

`B → C → D → A → A → D → C → B`

## 五、競賽規則

### 5.1 競賽準備

每場競賽開始前：

1. 所有玩家各自秘密選擇一張尚未使用的選手卡。
2. 所有人同時公開所選卡牌。
3. 將對應選手棋子放置於起點。
4. 第一場由全體玩家擲骰，最高者先行動。
5. 後續場次由上一場落後最遠的選手所屬玩家先行動；若有選手被淘汰，優先依最先淘汰者判定。

每張選手卡整局只能參賽一次。

### 5.2 玩家回合

每位玩家的回合依下列規則處理：

1. 處理「回合開始時」及「主要移動前」的能力。
2. 若選手未被絆倒，擲一顆六面骰。
3. 按骰子點數執行主要移動（Main Move）。
4. 處理移動期間、移動結束、角色能力及賽道效果。
5. 所有相關效果處理完成後，結束回合。
6. 由下一位玩家依順時針方向進行回合，除非能力改變行動順序。

主要移動專指玩家回合中原本應執行的擲骰移動。角色能力產生的額外移動，不會自動視為主要移動。

### 5.3 能力使用

- 能力敘述包含「可以」（Can）時，該能力為選擇性。
- 未標示可以的能力，符合條件時必須發動。
- 被動能力在條件成立時生效。
- 能力可能在其他玩家回合中觸發。
- 同時符合多個觸發條件時，依第七章的優先順序結算。

### 5.4 競賽結束

1. 第一名選手通過終點時，取得冠軍名次。
2. 第二名選手通過終點時，取得亞軍名次。
3. 第二名確定後，該場比賽立即結束。
4. 尚未完成比賽的選手不取得該場冠亞軍積分。
5. 已參賽的卡牌與棋子移出遊戲，不可重複使用。

## 六、場次與計分

### 6.1 賽道順序

| 場次  | 使用賽道       |
| --- | ---------- |
| 第一場 | Mild Mile  |
| 第二場 | Wild Wilds |
| 第三場 | Mild Mile  |
| 第四場 | Wild Wilds |

可在遊戲開始前共同約定不同的賽道順序，或全程使用同一面賽道。

### 6.2 積分取得

- 冠軍取得金色積分堆最上方一片。
- 亞軍取得銀色積分堆最上方一片。
- 特殊賽道或角色能力取得的銅色積分片，直接計入玩家總分。
- 後續場次的冠亞軍積分通常較高，依實際積分片印製的數值為準。
- 四場全部結束後，合計玩家取得的所有積分片。
- 分數最高者獲勝；同分者並列獲勝。

## 七、移動與能力判定

### 7.1 基本術語

| 術語                  | 定義                      |
| ------------------- | ----------------------- |
| 前方（Ahead）           | 停留在比另一名選手更接近終點的格子       |
| 後方（Behind）          | 停留在比另一名選手更接近起點的格子       |
| 獨處（Alone）           | 該格只有自己一名選手              |
| 最後一名（Last Place）    | 目前最接近起點的選手，可有多人並列       |
| 領先者（Lead）           | 目前最接近終點、尚未完賽的選手，可有多人並列  |
| 主要移動（Main Move）     | 玩家回合中正常執行的擲骰移動          |
| 移動（Move）            | 因主要移動、能力或其他效果而改變所在格子    |
| 超越（Passing）         | 一次移動開始時位於對方後方，結束時位於對方前方 |
| 同格（Sharing a Space） | 兩名以上選手停留於同一格            |
| 停留（Stopping）        | 選手完成移動或其他位置變更後，停在指定格子   |
| 絆倒（Trip）            | 跳過下一次主要移動               |
| 傳送（Warp）            | 直接改變位置，不視為移動            |

### 7.2 移動基本限制

1. 起點視為有效格子。
2. 終點以外的區域不視為賽道格子。
3. 移動 0 格不視為發生移動。
4. 主要移動及能力移動是不同的移動事件。
5. 移動途中暫時經過其他選手所在格子，不構成同格停留。
6. 一次移動的起點及終點決定是否構成超越。
7. 傳送不觸發以移動或超越為條件的能力。
8. 沒有其他限制時，超過抵達終點所需的移動距離仍可完成比賽。

### 7.3 絆倒規則

選手被絆倒時：

1. 先完成目前正在執行的移動。
2. 將棋子翻面，標示絆倒。
3. 下一次輪到該選手時，跳過主要移動，不擲骰。
4. 將棋子恢復正面，表示恢復正常。
5. 該回合仍可觸發角色能力。
6. 絆倒期間仍可透過其他角色能力或效果移動。

絆倒不會直接中止當前移動。

### 7.4 同時觸發的處理順序

當多個效果同時符合條件，依下列順序結算：

1\. 賽道格子效果

2\. 當前回合玩家的能力

3\. 其他玩家的能力（順時針順序）

額外規定：

- 同時到達同一格的選手，仍可觸發同格能力。
- 指定時間點發動的能力，例如「主要移動前」，每回合只能發動一次。
- 選手獲勝或離開競賽後，其能力停止生效，除非另有說明。
- 重擲時，先前骰值視為不存在，不觸發任何相關效果。
- 允許重擲時，只能重擲最近一次擲出的骰子。
- 發生真正的無限循環時，依序完整執行一次循環後停止；有限次的連鎖效果仍須繼續處理。

## 八、特殊賽道 Wild Wilds

| 格子圖示 | 效果                  |
| ---- | ------------------- |
| 箭頭   | 停在該格時，依箭頭方向移動指定格數   |
| 石頭   | 停在該格時，選手被絆倒         |
| 星星   | 停在該格時，取得一片 1 分銅色積分片 |

補充規則：

- 箭頭造成的移動是獨立移動，不屬於原本的主要移動。
- 箭頭移動可能繼續觸發其他格子或角色能力。
- 星星取得的分數直接計入玩家的總積分。
- 格子效果與角色能力同時觸發時，優先處理格子效果。

### 9.1 特殊角色補充裁定

Mastermind（策士）

預測自己並且最後成為冠軍時，可以同時取得冠軍與亞軍獎勵。

M.O.U.T.H.（大嘴怪）

若因淘汰能力造成沒有任何選手能取得第二名，該場亞軍獎勵不發放，對應銀色積分片棄置。

Scoocher（挪動者）

- Gunk 每次對某位選手的主要移動產生 -1 效果，視為一次可觸發事件。
- Dicemonger 造成的每次重擲，分別觸發。
- Leaptoad 跳過多個有選手的格子時，每個被跳過的格子分別觸發。
- Magician 每次重擲都可觸發，即使最終不採用該骰值。

Romantic（浪漫主義者）

若兩名選手一起移動並同時符合能力條件，例如 Suckerfish 跟隨另一名選手，可以分別觸發兩次。

Baba Yaga（芭芭雅嘎）

即使與 Duelist 同格並進行決鬥，決鬥者仍會絆倒。Hypnotist 對芭芭雅嘎施放能力時，也可能因同格而絆倒。

Skipper（船長）與 Inchworm（尺蠖）

當其他選手擲出 1 時，尺蠖的移動仍須處理，之後船長依能力取得下一個回合。

Suckerfish（吸盤魚）

決定跟隨一名選手後，必須跟隨到該次移動完成，不得中途停止。

## 十、雙人遊戲變體

雙人遊戲採用以下獨立規則，未提及部分沿用一般規則。

### 10.1 選秀

1. 公開 8 張選手卡。
2. 依蛇形順序選秀：`A → B → B → A → A → B → B → A`。
3. 再公開 8 張全新選手卡。
4. 第二次選秀反轉起始順序。
5. 最終每位玩家取得 8 名選手。

### 10.2 競賽

- 每場比賽，每位玩家同時派出 2 名不同選手。
- 每場共有 4 名選手。
- 每位玩家使用 2 顆骰子，分別對應自己的選手。
- 每位玩家第一次行動時，可以自行決定先使用哪名選手。
- 後續回合可自行決定兩名選手的行動順序，但必須完整處理一名選手後，才能處理另一名。
- 能力敘述中的「其他選手」包含自己控制的另一名選手。
- 第二場起，由上一場得分較低的玩家先行動；平手時擲骰決定。

## 十一、三人雙選手變體

### 11.1 選秀

1. 每次公開 6 張選手卡。
2. 使用一般蛇形選秀。
3. 共進行 4 次選秀，每次輪換起始選秀玩家。
4. 每位玩家最終取得 8 名選手。

### 11.2 競賽

- 每位玩家每場派出 2 名選手。
- 每場共有 6 名選手。
- 每位玩家使用 2 顆骰子。
- 玩家每回合自行決定兩名選手的行動順序。
- 必須先完整處理一名選手，再處理另一名。
- 「其他選手」包含自己控制的另一名選手。

## 十二、規則爭議處理

依英文規則書，遇到未能明確解決的特殊互動時：

1. 優先適用角色卡及規則書明確記載的效果。
2. 同時觸發依「賽道 → 當前玩家 → 其他玩家順時針」處理。
3. 無限循環只完整執行一次。
4. 仍無法判定時，可由相關玩家擲骰決定。
